# Cristian Aranda

I am building a small platform on AWS and I run it as if it were production. It is a lab, not a real company.

You will not find tutorials here. I write about the decisions I make while I build it. I explain what options I had, why I picked one, what broke and what I would do differently next time.

I spent eight years in the SRE team of a bank, working on-premise with automation and monitoring. In November 2026 I started my move into cloud infrastructure engineering on AWS.

Right now I am making a new AWS account safe before I build anything on it.

I am based in Mexico and I work remotely.
